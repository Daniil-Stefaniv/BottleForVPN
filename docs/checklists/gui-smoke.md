# Ручной smoke-чеклист GUI (0.3 «Погребок», Task 20)

CI собирает GUI (джоба `gui-build`: eslint → vitest → fmt/clippy → cargo
test → tauri build), но поведение окна на CI не проверяется — этот
чеклист прогоняется вручную перед релизом (macOS и Windows).

Запуск для проверки: `cd gui && npx tauri dev` с подсунутыми бинарниками
(`POGREBOK_GUI_CLI_BIN=<путь к pogrebok> POGREBOK_GUI_DAEMON_BIN=<путь к
pogrebok-daemon>` для macOS-хоста; на Windows бинарники находятся рядом
с exe/в PATH).

## Блокировка и миграция (0.3, Tasks 8–10)

- [ ] Первый запуск: экран мастер-пароля (создание), без пароля дальше
      не пускает; повторный запуск — экран разблокировки.
- [ ] Неверный пароль — понятная ошибка, окно остаётся на блокировке.
- [ ] Профили 0.2.x (`%LOCALAPPDATA%\BottleForApps\bottles\*.toml`)
      найдены: диалог миграции, после подтверждения бутылки в списке,
      битый TOML пропущен с предупреждением, остальные перенесены.
- [ ] Пароль + Unicode/эмодзи принимается и открывает базу после
      перезапуска.

## Список и управление (0.3, Tasks 14–16)

- [ ] Окно открывается, заголовок «Погребок», вкладки **Env** и **Host**;
      бутылки видны даже при остановленном демоне (из БД).
- [ ] Демон остановлен: панель с кнопками «Запустить демона» /
      «Остановить демона»; журнал демона после запуска виден.
- [ ] Состояния прилетают push-событиями (StateChanged), без перезагрузки
      окна; состояние/порты меняются на карточке.
- [ ] Старт бутылки: команды карточки блокируются на время `starting`.
- [ ] Сетка команд карточки ровная: «Старт/Стоп», «Изменить»,
      «Обновить логин и пароль», «Удалить» — одинаковые размеры.
- [ ] «Обновить логин и пароль»: модальное окно (блокирует основное),
      ввод + «Сохранить», тост об успехе; OpenVPN-бутылка стартует без
      диалога кредов.
- [ ] «Создать»/«Изменить» — модальное окно поверх основного (основное
      заблокировано); id занят — понятный отказ, БД не тронута.
- [ ] Остановка host-бутылки: тост с предупреждением «VPN-клиент остаётся
      запущенным».

## Диагностика и консоль (0.3, Task 17)

- [ ] Вкладка «Диагностика»: карты состояния (демон, WSL/апплайенс,
      служба, БД) обновляются.
- [ ] Doctor: таблица ✓/⚠/✗, «Проверить снова» перечитывает.
- [ ] «Собрать логи»: путь к ZIP показан, «Открыть папку» открывает
      Finder (macOS) / Explorer (Windows) с выделенным файлом.
- [ ] Консоль событий: колонки уровень/дата/событие/описание; фильтр по
      уровню работает; события GUI (команды) и демона прилетают живьём;
      поиск с дебаунсом; длинный лог не тормозит окно.
- [ ] «Открыть папку логов» в подвале консоли открывает каталог с
      `gui-*.jsonl` и журналами демона.
