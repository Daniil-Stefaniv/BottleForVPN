BottleForApps — установка

Windows 10/11 x64:
1. Распакуйте BottleForApps-Windows-x64.zip.
2. Запустите Install-BottleForApps.bat двойным кликом — execution policy не мешает.
3. Подтвердите единственный запрос прав администратора — он нужен, чтобы зарегистрировать
   службу маршрутов. После этого приложению повышение прав не требуется.
4. Запускайте BottleForApps ярлыком с рабочего стола или из меню «Пуск».

macOS 12+ Apple Silicon:
1. Откройте BottleForApps-macOS-arm64.dmg и перетащите BottleForApps в «Программы».
   Альтернатива для корпоративного развёртывания — BottleForApps-macOS-arm64.pkg.
2. Установщик pkg один раз попросит пароль администратора: он ставит службу маршрутов
   (bottle-route-helper) и создаёт ссылку bottle в /usr/local/bin. Дальше запросов не будет.
3. Запустите BottleForApps из каталога «Программы».
4. Пакет использует локальную ad-hoc подпись. Если macOS предупредит о неизвестном разработчике,
   откройте приложение через контекстное меню «Открыть» или разрешите его в «Конфиденциальность и безопасность».

Графический интерфейс:
- Приложение открывается в собственном окне (браузер не нужен).
- Повторный запуск не создаёт второй копии приложения.
- Закрытие окна с активными подключениями требует подтверждения.
- Если окно недоступно, панель откроется в браузере (или запустите: bottle gui browser).

Служба маршрутов:
- Изменение временных маршрутов VPN endpoint выполняет служба, поэтому прав администратора
  при каждом подключении не требуется.
- Если служба не установлена, приложение работает по прежней схеме: на Windows нужен
  терминал администратора, на macOS появится системный запрос.

Диагностика:
- В GUI: «Как это работает» → «Если не работает» → «Собрать логи».
- В терминале: bottle doctor (строка «Служба маршрутов»), bottle logs export
- bottle routes cleanup удаляет маршруты, оставшиеся после аварийного завершения.
- Отправьте созданный bottle-support-*.zip разработчику.
- Архив не содержит паролей, но содержит технические пути, имена сетевых интерфейсов,
  IP-адреса и VPN endpoint. Просмотрите его перед отправкой, если это важно для вашей политики.
