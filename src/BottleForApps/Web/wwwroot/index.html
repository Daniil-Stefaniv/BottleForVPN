Для Windows 10/11

При подключении может появиться запрос прав администратора. Нажмите «Да»: они нужны только для временного сетевого маршрута. RDP уже встроен в Windows.

Для macOS 12 и новее

Заранее установите Windows App из App Store. macOS отдельно попросит разрешение на изменение маршрута — подтвердите системный запрос.

Карта приложения

Что находится на каждой вкладке

Подключения

Главный экран для ежедневной работы. Здесь лежат карточки ваших профилей — например, «Главный офис» и «Склад».

  • Всего профилей — сколько связок VPN + RDP сохранено.
  • Активные сессии — сколько подключений работает сейчас.
  • Состояние системы — готов ли компьютер к запуску.
  • На карточке: адрес рабочего компьютера, VPN-сервер, состояние и кнопки запуска, изменения и удаления.

Сеть

Диагностический экран. В обычной работе сюда заходить не обязательно.

  • IPv4 — адрес компьютера внутри конкретной сети.
  • Шлюз — устройство, через которое идёт интернет.
  • Работает — адаптер сейчас включён.

Полезно, если Bottle не смог автоматически найти VPN-интерфейс: сравните список до и после включения VPN.

Создание профиля

Что вводить в каждое поле

Профиль — это сохранённый рецепт одного подключения. Поля со звёздочкой обязательны.

НазваниеПридумайте сами

Любое понятное вам имя: «Рабочий компьютер», «Офис Москва» или «Бухгалтерия».

Главный офис
VPN-клиентВыберите программу

Нажмите «Выбрать…» и укажите приложение, которым вы обычно включаете рабочий VPN. Не выбирайте ярлык или установщик.

Windows: C:\Program Files\Vendor VPN\vpn.exemacOS: /Applications/Vendor VPN.app
Публичные адреса VPNСпросите у администратора

Адрес сервера, к которому подключается VPN-клиент. Один адрес на строку. Не вводите сюда адрес рабочего компьютера, сайт компании, логин или пароль.

vpn.company.ru

Если VPN использует несколько серверов, добавьте каждый с новой строки.

RDP-адресСпросите у администратора

Внутренний адрес удалённого рабочего компьютера. Часто начинается с 10., 172.16–31. или 192.168.

10.20.30.15
RDP-портОбычно не меняйте

Оставьте 3389, если администратор не назвал другой порт.

Дополнительные параметрыОбычно оставьте пустыми
Аргументы VPN-клиента
Команды для особого способа запуска. Заполняйте только по готовой строке от администратора.
VPN-интерфейс
Имя сетевого адаптера VPN. Пустое поле означает автоматический поиск.
Основной интерфейс
Wi‑Fi или Ethernet, через который есть интернет. Пустое поле означает автоматический выбор.
Локальный порт релея
Оставьте 0 — Bottle сам найдёт свободный порт.
Где логин и пароль?

Их намеренно нет в профиле. Вводите секретные данные только в официальных окнах вашего VPN-клиента и RDP-приложения.

Ежедневная работа

Подключение — шаг за шагом

  1. 1

    Нажмите «Подключиться»

    Статус карточки сменится с «Готов» на «Подключение».

  2. 2

    Подтвердите системный запрос

    На Windows нажмите «Да» в запросе контроля учётных записей. На macOS подтвердите изменение сетевого маршрута.

  3. 3

    Подключите VPN

    В открывшемся VPN-клиенте выберите нужное подключение, введите логин/пароль и дождитесь статуса Connected / Подключено.

  4. 4

    Дождитесь удалённого рабочего стола

    Bottle распознает VPN и откроет RDP. Введите учётные данные рабочего компьютера, если приложение их запросит.

  5. 5

    Завершите работу

    Закройте окно удалённого рабочего стола и нажмите «Остановить» в Bottle. VPN-клиент при необходимости отключите отдельно.

Простыми словами

Словарь терминов

VPN

Защищённый «коридор» от вашего компьютера в рабочую сеть компании.

RDP / удалённый рабочий стол

Способ видеть экран рабочего компьютера и управлять им через интернет.

Профиль

Сохранённый набор настроек для одной пары: конкретный VPN + конкретный рабочий компьютер.

VPN endpoint

Публичный адрес входа в VPN. В интерфейсе он называется «Публичные адреса VPN».

Сетевой интерфейс / адаптер

Программный или физический сетевой канал: Wi‑Fi, Ethernet или канал, созданный VPN.

IPv4-адрес

Числовой адрес устройства в сети, например 10.20.30.15.

Порт

Номер конкретной сетевой службы. Для RDP стандартный порт — 3389.

Маршрут

Правило, которое говорит компьютеру, через какое подключение отправлять конкретный сетевой трафик.

TCP-релей

Локальный посредник Bottle, который направляет RDP именно в нужный VPN. Настраивать его вручную обычно не требуется.

Данные остаются на компьютере

Панель открывается только локально. Профили не отправляются во внешнюю сеть, а пароли Bottle не запрашивает и не хранит.
